# HTML and React

**HTML** renders plain markup with `odd-*` classes, the way you'd write it by hand.
**React** renders the same stories with the components from `odd-design/react`.
Both come from one story list (`stories/components/`), and the browser sweep checks that each pair
looks the same and has the same accessibility tree. The stories that only exist under HTML are the
foundations, the showcase, the recipes, and the vanilla avatar fallback.

To try chromes, palettes, and modes, open a section on its own (the globe menu next to its title).
